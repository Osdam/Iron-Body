## Hito 5 (gobierno y versionado)

Ninguno de estos scripts imprime valores del fichero de entorno, tokens, contraseñas ni el id de la conversación canaria. Los que se ejecutan en el servidor se copian desde el Mac, con el árbol en el commit desplegado, y se comparan las huellas antes de usarlos (`shasum -a 256` en el Mac, `sha256sum` en el servidor): así root no ejecuta git más de lo imprescindible (M-3). Procedimiento completo, por fases, en `../ULTRON_STUDIO_DEPLOYMENT_PLAN.md` («Hito 5»); vuelta atrás en `../ULTRON_STUDIO_ROLLBACK.md` («Hito 5»).
